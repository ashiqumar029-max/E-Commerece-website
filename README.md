# TECHVAULT — Tech E-commerce Store

A responsive, front-end demo storefront for tech accessories and gadgets.

## Files
- `index.html` — page structure
- `style.css` — responsive visual styling
- `script.js` — product filters, search, sorting, cart, and demo newsletter
- `README.md` — this guide

## Run locally
1. Keep all files together in the same `techvault-store` folder.
2. Open `index.html` in a browser, or open the folder in VS Code and use Live Server.
3. Internet is needed for Google Fonts and the product photography URLs.

## Features
- Responsive dark hero and premium storefront design
- Product cards with category filtering
- Search and price/name sorting
- Working cart drawer with quantity controls and subtotal
- Demo newsletter confirmation
- Mobile navigation

## Important
This is a front-end portfolio demo. Checkout does not accept payments, and newsletter submissions are not saved. Product images are loaded from Unsplash.
