# Atelier Home — Furniture & Home Objects Store

A third portfolio e-commerce concept, deliberately styled differently from a typical dark tech store: warm editorial colors, serif typography, large interior photography, minimal navigation and a journal section.

## Files
- `index.html` — page structure
- `style.css` — styling and responsive layouts
- `script.js` — product catalogue, filters, search, sort, cart and demo newsletter
- `README.md` — project notes

## Run
Keep all four files in the same `atelier-home` folder, then double-click `index.html` to open it in a browser. For development, open the folder in VS Code and use Live Server.

## Features
- Furniture product catalogue with four categories
- Search, sorting and responsive layouts
- Shopping bag with quantity controls and subtotal
- Editorial collection and journal sections
- Newsletter demo confirmation

## Note
This is a front-end portfolio demo. Checkout does not take real payments and newsletter entries are not stored. Product photography and web fonts require an internet connection.
